# Arabic terminology

Standard Arabic. Brand names, model names, IMEI, ICE, RIB, SKU codes and amounts in DH stay in Latin script.

Notes

- Do not describe positions as "right"/"left" in Arabic text: the layout is mirrored. Say "المجاورة" (adjacent).
- Stored values (movement reasons, clothing colours and sizes, category names) are kept in French in the database and
  translated when displayed.
